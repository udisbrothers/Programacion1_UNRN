Una lista es una serie de elementos que se guardan en un orden determinado. Los elementos pueden repetirse y se pueden modificar, agregar o eliminar después de crear la lista, a diferencia de una tupla no e puede modificar. Luego el conjunto es una serie de elementos que no admite duplicados, pero sí se puede modificar. Por ultimo el diccionario es una serie de elementos con carácter clave-valor lo que significa que cada elemento dentro del mismo tiene una llave asociada, destacándose por admitir duplicados en los valores pero no en las llaves. En resumen de diferencias... La lista es mutable mientras que la tupla no, ademas el set no tiene orden al igual que los diccionarios, ya que no podes pedir un elemento mediante indice. El set no admite duplicados mientras que el resto sí excpeto en las llaves de los diccionarios.

Lista_notas = [4,7,4,9]
